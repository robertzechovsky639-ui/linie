# LINIE

Denní tenisová deska pro ATP, WTA a Challenger. Pravděpodobnosti jdou z žebříčkového ratingu a z online Elo (K = 24), které se v prohlížeči posune, když zapíšete výsledek. Živý panel skládá rating, stav skóre a únavu. Není to sázkové poradenství.

Snímek zápasů z 3. října 2026 je v `data.json`. Kurzy jsou jen tam, kde šel stáhnout veřejný desetinný kurz. Chybějící kurz je označený, není vymyšlený.

Otevření: otevřete `index.html` v prohlížeči, nebo `python3 -m http.server` v této složce.
